# Raport Integrasi Al-Ghozali V5.2

Clean baseline for GitHub Pages.

- Frontend: React + Vite + TypeScript
- Hosting: GitHub Pages
- Authentication target: Google Identity Services
- Backend target: Google Apps Script
- Data source: Google Sheets
- No Vercel
- No Supabase
- No Firebase
- No dummy production data

Run:
npm install
npm run dev
npm run build
